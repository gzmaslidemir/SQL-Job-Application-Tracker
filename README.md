# SQL Job Application Tracker

## Project Overview

This project is a SQL Server database designed to track job applications throughout the hiring process. It stores information about companies, applications, recruiters, and interviews, allowing users to organize and analyze their job search.

## Features

- Store company information
- Track job applications and their status
- Manage recruiter information
- Record interview details
- Generate reports using SQL queries

## Database Tables

- Companies
- Applications
- Recruiters
- Interviews

## SQL Skills Demonstrated

- Database Design
- Primary & Foreign Keys
- SELECT Statements
- WHERE Filtering
- ORDER BY
- GROUP BY
- Aggregate Functions (COUNT)
- INNER JOIN
- Multi-table Queries

## Project Structure

- `create_tables.sql` – Creates the database schema
- `insert_data.sql` – Inserts sample data
- `queries.sql` – SQL queries and reports

## Example Reports

- View all companies
- View all applications
- Filter applications by status
- Sort applications by application date
- Count applications by status
- Company and application report
- Multi-table interview report

## Technologies

- Microsoft SQL Server
